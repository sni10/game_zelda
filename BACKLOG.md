### 🟢 v0.4.2b — Оружейные модули для Rifle (идея зафиксирована 2026-07-26, не начато)

Пользователь: «просто райфл — скучно». Лёгкая версия affix-системы (см. v0.5.1) уже сейчас
для одного оружия, без ожидания data-driven миграции (v0.5.0) — модули как аффиксы поверх
существующего `Weapon`, не отдельные классы/YAML.

**Модули (2-3 хватит на первую итерацию):**
- `explosive_rounds` (разрывные патроны) — пуля взрывается при попадании небольшим AoE,
  а не наносит урон только тому врагу, в кого попала
- `extended_magazine` (увеличенный магазин) — `magazine_size` × множитель
- `shotgun_spread` (дробовик-режим) — веером N пуль по углу поражения вместо одной прямой;
  урон по площади **чуть больше взрыва гранаты** (ориентир: `AoeWeapon` 96×96, т.е. область
  дробовика примерно 100+px)

**Более широкая прогрессия-фантазия от пользователя (не обязательна к реализации сразу,
зафиксирована для контекста):** 1 пуля → 3 пули веером → пули покрупнее (урон/размер) →
3 крупные пули → режим огнемёта. Модули выше — практичный минимум с той же сути.

**Находка, не левелап-перк:**
- [ ] Оружие (в т.ч. новые типы вроде `Flamethrower`) **дропается у трупов врагов** —
  пересекается с уже запланированным v0.4.2 «враги дропают оружие с шансом», делать вместе
  с v0.4.2, не отдельной системой
- [ ] Модули дропаются/находятся отдельно от самого оружия и монтируются на него
- [ ] Смена найденного оружия в бою уже работает «из коробки» (слоты 1-8 + `Tab` цикл по
  каталогу, см. `PlayerCombat`) — находка через будущий `WeaponPickup` лишь добавляет новый
  `weapon_id` в оборот, архитектурных изменений в `PlayerCombat` не требует
- [ ] Где монтировать модуль на оружие — нужен UI (экран инвентаря v0.4.3 ещё не готов;
  либо временный стаб-хоткей «применить модуль к текущему оружию»)
- [ ] `Flamethrower` — новый `ammo_type` (например `"fuel"`), отдельный от `"bullets"`

**Открытый вопрос:** огнемёт — это `fires_projectile`-снаряд с очень коротким `max_range` и
частым тиком урона, или принципиально третий тип атаки (непрерывный конус/луч, ближе к
DoT-механике, не дискретные выстрелы)? Решить прототипом, когда дойдёт очередь.
