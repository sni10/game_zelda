Базовая реализация игры в стиле классической 2D Zelda с использованием Python и Pygame.

## Особенности

### ✅ Реализованные функции

#### 🎮 Игровые системы
- **Главное меню**: Полноценное меню с навигацией и динамическими опциями
- **Система состояний**: MENU, PLAYING, GAME_OVER с плавными переходами
- **Экран Game Over**: Информативный экран смерти со статистикой

#### 👤 Персонаж и здоровье
- **Движение**: Свободное движение в любом направлении относительно прицела
- **Система здоровья**: HP с визуальной полоской здоровья
- **Смерть игрока**: Автоматический переход в Game Over при 0 HP
- **Бой**: Ближнее и дальнее оружие с кулдаунами, патронами и перезарядкой

#### 🌍 Мир и ландшафт
- **Большой мир**: Игровая карта 2000x2000 пикселей
- **Система ландшафта**: Несколько типов terrain с различными свойствами
- **Урон от ландшафта**: Болота и пески наносят урон игроку
- **Модификация скорости**: Некоторые типы ландшафта замедляют движение
- **Загрузка карт**: Поддержка ASCII карт из файлов

#### 💾 Сохранения и статистика
- **Быстрые сохранения**: F5 для сохранения, F9 для загрузки
- **JSON формат**: Структурированные сохранения с версионированием
- **Игровая статистика**: Время игры, урон, собранные предметы, расстояние
- **Автоматическое отслеживание**: Все действия записываются в статистику

#### 🖥️ Интерфейс
- **Камера**: Плавное следование за игроком с ограничениями по границам мира
- **Коллизии**: Система столкновений с препятствиями и ландшафтом
- **Мини-карта**: Отображение позиции игрока и области видимости
- **Инвентарь**: Экран слотов оружия с перетаскиванием мышью
- **Отладка**: F1 для включения/выключения отладочной информации

### 🎮 Управление

#### В меню:
- **Стрелки вверх/вниз** - навигация по пунктам меню
- **Enter** - выбор пункта меню
- **ESC** - выход из игры

#### В игре:
- **Мышь** - прицел (360°), игрок всегда смотрит на курсор
- **WASD** - движение относительно прицела: **W** вперёд, **S** назад, **A/D** — вбок
- **Пробел** или **ЛКМ** - атака/выстрел в направлении прицела
- **Shift** - спринт
- **1-8** - выбор слота оружия
- **R** или **ПКМ** - перезарядка
- **I** - открыть инвентарь
- **F1** - включить/выключить отладочную информацию
- **F5** - быстрое сохранение (quicksave)
- **F9** - быстрая загрузка (quickload)
- **ESC** - возврат в главное меню

#### На экране Game Over:
- **WASD/Стрелки** - навигация по опциям
- **Enter/Пробел** - выбор опции

### 🎨 Визуальные элементы
Вместо текстур используются простые геометрические фигуры:

#### Игрок и интерфейс
- **Игрок**: Зеленый прямоугольник (красный во время атаки)
- **Направление взгляда**: Белая точка на игроке
- **Атака**: Цветная область в направлении прицела (цвет зависит от оружия)
- **Полоска здоровья**: Красно-зеленый градиент в верхней части экрана

#### Ландшафт
- **Пустота**: Темно-зеленый фон
- **Горы**: Темно-серые блоки (непроходимо)
- **Вода**: Синие блоки (непроходимо)
- **Деревья**: Темно-зеленые блоки (декоративные)
- **Болота**: Коричнево-зеленые блоки (урон)
- **Пески**: Песочные блоки (урон + замедление)

#### Интерфейс
- **Мини-карта**: Правый верхний угол с точками игрока и препятствий
- **Меню**: Стилизованное с желтым выделением и стрелками
- **Game Over**: Полупрозрачный оверлей с красным заголовком

## Запуск игры

